# Roadmap

1. Compilación TypeScript estricta y matriz Node/Bun; paquetes independientes.
2. Tokenizadores oficiales de al menos dos familias, métricas exactas de solicitud completa y costos auxiliares.
3. Corpus diverso con licencias verificadas, baseline de resumen, precisión funcional en modelos, latencia y pruebas adversariales.
4. Evaluar hook profundo OpenCode V1/V2; conexión MCP e instalador ya verificadas.
5. Extender MCP stdio existente con compatibilidad adicional; gateway remoto autenticado y A2A.
6. Gramática y VSR extendidas: actores, tiempo, epistemología, unidades y restricciones tipadas; vocabulario propuesto y evaluado.
7. Studio con configuración y métricas reales de proveedores; seguridad multiusuario y credenciales OS.
