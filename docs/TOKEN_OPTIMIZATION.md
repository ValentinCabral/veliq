# Medición

El contador del runtime mide bytes UTF-8 exactos para un perfil byte a byte artificial; **no es un tokenizador de GPT, Claude ni otro LLM**. El estimador `ceil(bytes/4)` está etiquetado como estimación. `hybrid` acepta una candidata formal sólo si conserva VSR en round-trip y `(candidato + overhead) < original` bajo el mismo contador. C1 se considera únicamente con `compactNegotiated: true` proporcionado por el llamador; el MCP en Hybrid no declara esa negociación. `observe` mantiene original. El benchmark offline cuenta tokens de **texto** con la biblioteca oficial `tiktoken` en dos encodings, sin mezclarlos con bytes o uso reportado. No hay contabilidad de tokens de salida, llamadas de traducción LLM, reintentos ni precios de proveedor: no se informa ahorro monetario. Comparación con resumen convencional y pruebas de comprensión pendientes. Ver `docs/BENCHMARKS.md`.
