# Medición

El contador predeterminado del runtime mide bytes UTF-8 exactos para un perfil byte a byte artificial; **no es un tokenizador de GPT, Claude ni otro LLM**. El MCP ofrece opcionalmente conteo exacto de texto mediante Python `tiktoken` para `cl100k_base` y `o200k_base`; no equivale a solicitudes completas ni a consumo reportado. El estimador `ceil(bytes/4)` está etiquetado como estimación. `hybrid` acepta una candidata formal sólo si conserva VSR en round-trip y `(candidato + glosario completo) < original` bajo el mismo contador. Un fallback no paga el glosario descartado. C1 se considera únicamente con `compactNegotiated: true` proporcionado por el llamador; el MCP en Hybrid no declara esa negociación. `observe` mantiene original. El benchmark de recuperación selectiva mide una tarea exacta y compara con búsqueda convencional; la ventaja frente a reenviar todo el documento no es exclusiva de VELIQ. No hay contabilidad de tokens de salida, llamadas de traducción LLM, reintentos ni precios de proveedor: no se informa ahorro monetario. Comparación con resumen convencional y pruebas de comprensión pendientes. Ver `docs/BENCHMARKS.md`.
