# Seguridad 0.1

Sin claves, red saliente ni cambios automáticos a harnesses. Servicio HTTP vinculado a loopback; no exponer mediante proxy público. `observe` no altera mensajes; las plantillas desconocidas fallan cerrado. Literales escapados y referencia SHA-256 validada. SQLite aísla recuerdos por usuario/workspace/proyecto/sesión/agente. El esquema guarda cuerpos en texto plano local: no introducir secretos. La API web local carece aún de autenticación y protección CSRF para ambientes multiusuario; ejecutar sólo en equipo confiable. El envelope detecta manipulación accidental, pero no identidad ni autenticidad. Las prioridades/autoridades no se elevan mediante transformación; falta política completa de taint y pruebas adversariales amplias.

La ingesta de benchmarks está desactivada sin `VELIQ_INGEST_TOKEN` de al menos 16 bytes; compara el bearer con tiempo constante y limita cuerpos a 64 KB. No exponer el gateway sin un proxy HTTPS y autenticación adicional. La carga externa no recibe acceso a memoria ni ejecuta comandos. `run_id` duplicados se rechazan. El contenido de `notes` no se muestra sin escape HTML.

El servidor MCP valida entradas con Zod, exige ámbito explícito para memoria, limita tamaño de textos y devuelve errores de ejecución con `isError`. Sólo se inicia si un cliente lo configura o al ejecutar `npm run mcp`. Los permisos para invocar herramientas los controla el harness; revisar la configuración antes de aprobarla en Claude Code u otro cliente. Las herramientas de memoria guardan datos locales en texto plano y `benchmark.ingest` acepta cifras autodeclaradas. No hay promoción de autoridad de contenido externo a instrucciones del sistema.
# Observadores diarios

Los hooks Observe no devuelven contexto ni decisiones de permiso: stdout vacío y exit 0 en el receptor Codex/Claude. Nunca leen transcripciones o argumentos de herramientas. Metadatos en `.veliq/observations.jsonl`, permisos 0600 y límite de 10 MB; se rechazan symlinks y registros inválidos. Esto no cifra la información ni reemplaza la seguridad del workspace. Instalar exige conservar la ruta del clone y respetar revisión/confianza de cada harness. No se configura bypass de aprobaciones.

La captura `VELIQ_CAPTURE_CONTENT=1` de OpenCode es explícita, separada y desactivada por defecto. Puede incluir secretos presentes en resultados: revisar/redactar antes de compartir o subir. La observación normal no almacena esos cuerpos y no realiza envíos. Los recibos/respaldos permiten desinstalar sólo hooks propios sin pisar ajustes ajenos; si una entrada fue modificada, se detiene la desinstalación.

## Transformación nativa alpha.7

Transformaciones sobre outputs únicamente: JSON lexical sin espacios fuera de strings, referencias a resultados idénticos anclados en la misma solicitud. Nunca comandos/inputs/roles/confirmaciones. Allowlist, modelo/gate, costo local y logging seguro son obligatorios; fallos vuelven al original. Claude mantiene el esquema, stderr e interrupciones/imagenes, evita subagentes de modelo desconocido y no agrega additionalContext/classifierContext. No se lee transcript_path. Context snapshots preservan authority y constraints; cambio de autoridad requiere nuevo ID. Hash/ACK no autentican extremos remotos. Auditoría privada bounded, sin cuerpos/args/hashes/call IDs. Modelo de sesión Claude se guarda por hash del session ID, sólo metadata local. Research necesita marcador del workspace aislado explícito; no cambia producción automáticamente. Gates locales son evidencia aprobada por el usuario, no certificados firmados. Revalidar tras actualizaciones; credenciales sólo gestionadas por harness/variables, jamás en reportes o archivos versionados.
